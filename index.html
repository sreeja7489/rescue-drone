Problems this design targets
  • Needs trained pilots, slow manual analysis → autonomous lawn-mower search plus on-board AI detection that flags people live.
  • Cloud/GPU dependence → edge AI computer runs the model offline.
  • Weak thermal in vegetation, wet clothing, low contrast → thermal + RGB + LiDAR fusion, not thermal alone.
  • False positives/negatives → multi-sensor confirmation, confidence scores, human verifies before dispatch.
  • GPS-denied, obstacle-rich zones → LiDAR + visual-inertial odometry + SLAM.
  • Poor communications → mesh radio relay; drone keeps working if the link drops.
  • Battery, coordination, cost → swappable battery, swarm-ready mesh, off-the-shelf parts.
  • Beyond just “finding” → builds a hazard map and ranked victim list for the commander.
  • Slow escalation → emergency alert module messages the command centre and 112 with GPS location and a snapshot.
  • Bystanders unaware of danger → amplified hazard horn warns the surroundings.
  • Unverified detections → command centre receives the alert and can confirm or cancel before teams are sent.
